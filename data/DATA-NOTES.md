# data/english-words.txt — 內建英文詞頻表

## 檔案事實

| 項目 | 值 |
|---|---|
| 來源 | 從本機已安裝的 ZingIME.app v3.1 (build 2026102701) 的 `Contents/Resources/english-words.txt` 取出,供設計/原型使用 |
| 大小 | 3.3 MB,ASCII |
| 行數 | 227,921 |
| 格式 | TSV:`word<TAB>count`,count 為整數詞頻,無表頭 |
| 完整性 | 全部 227,921 行皆為 2 欄、第 2 欄全為數字(0 列例外) |
| SHA-256 | `acebeca02e45ccbda39df5263c0aaa11fe77cc7390302e160204cee3c398846e` |

## 用途

作為 `EnglishPredictionEngine` 的內建詞庫來源:啟動時載入為前綴 trie,排序權重 = `word_count`(再乘本機 usage 記憶的衰減分數);使用者自訂詞以 `english-words-user.txt` 覆蓋在最前。

## 載入器約定(供 M2 實作)

```
- 逐行 split('\t') → (word, Int(count))
- 忽略空行與格式不符的行(此檔為 0 筆,但仍要防禦)
- trie 節點只存子節點 map + 該前綴前 K 名的 (word, count)(top-K 可在 build 時預計算)
- 228k 詞預估記憶體 < 20 MB;載入 < 150 ms,可背景載入而不阻塞 IME 啟動
```

## 衍生清單:chinese-common-10000(2026-11 產生)

來源:本機 ZingIME.app `Contents/Resources/data.txt`(小麥注音格式 `org.openvanilla.mcbopomofo.sorted`),**原始 data.txt 未收進本 repo**(授權考量);此清單為衍生結果。

| 檔案 | 內容 |
|---|---|
| `chinese-common-10000.txt` | 10,000 個中文常用字詞,一行一詞,**依聚合詞頻由高到低排序** |
| `chinese-common-10000.tsv` | `詞<TAB>聚合分數<TAB>讀音(以 | 分隔)`;讀音為注音,多讀音依分數排序 |

**產生方法**
1. 解析每行 `讀音 詞 分數`(分數為 log10 機率,越接近 0 越常見);跳過 `#` 與 `_ctrl_` / `_digit_` / `_number_` 控制項。
2. 只保留含漢字的詞,依詞分組。
3. 同一詞的多個讀音以 log-sum-exp(底 10)聚合:`score = max + log10(Σ 10^(s-max))`。
4. 依聚合分數降序取前 10,000;同分以詞排序。

**統計**
- 來源 165,099 行 → 非控制項 162,662 筆 → 唯一漢字詞 **154,020**。
- 第 10,000 名門檻:`一文` = **-5.081894**。
- 聚合後覆蓋率:占全部詞機率質量 **89.75%**。
- 其中 1,187 個詞有多讀音(已聚合)。
- 長度分佈:1 字 2,647、2 字 5,931、3 字 1,174、4 字 224、5 字 12、6 字 12。
- SHA-256:
  - `.txt`:`f5c415db0f79f2aa4fe32f35fbaaa545fe701e56640c17d1fc52f23fbdb59228`
  - `.tsv`:`7940d236b60713f6325e1ac18b14f2bdc3776ff62de7155a774fed6ac13f029e`

**已知限制**
- 語料偏新聞/書面語,包含「本報訊」「觀光局」等新聞用語;不是以對話語料為主。
- 前 10,000 名以單字(2,647)與二字詞(5,931)為主,長詞較少。
- 與英文清單相同,這是**種子清單**,非人工校對金標;正式發佈前建議人工審閱。
- 授權沿革與 `data.txt` 相同:取自商業 app 的安裝包,公開收錄不代表取得散布授權;若權利人要求將移除。

## 衍生清單:english-common-100000(2026-11 產生)

| 檔案 | 內容 |
|---|---|
| `english-common-100000.txt` | 100,000 個常用詞,一行一詞,**依詞頻由高到低排序** |
| `english-common-100000.tsv` | 同順序,`word<TAB>count`(供引擎載入權重) |

**產生方法**
```bash
sort -t$'\t' -k2,2nr english-words.txt | awk -F'\t' '
  $1 ~ /^[a-z]+$/ && length($1) <= 20 &&
  (length($1) > 1 || $1 == "a" || $1 == "i") &&
  $1 !~ /^(www|http|https)$/ { print $1"\t"$2 }
' | head -100000
```

**統計**
- 來源 227,921 詞 → 通過基本格式過濾 220,798 詞 → 取詞頻前 100,000(約占來源可用詞的 45%)。
- 第 100,000 名詞頻門檻:`radda` = 61,295。
- 覆蓋率:這 100,000 詞占來源語料總詞頻的 **98.05%**。
- 全部為小寫 ASCII(`^[a-z]+$`),長度 1–20;保留 `a`/`i` 兩個單字母。
- SHA-256:
  - `.txt`:`fdcaec1e224846ad321fe7bd1bc93249dae7d31ecc7fca06601a5ee8d7b9cae6`
  - `.tsv`:`ab593ec2efd9862a683628238aa0a84cc997c66c759276bb4b05047ffc7b2e72`

**已知限制(使用前請讀)**
- 來源是網頁語料詞頻,含**專有名詞/地名/人名**、**品牌**、**拼寫變體/錯字**,以及刻意保留的技術縮寫(tv、dvd、rss、pdf、html、sql 等)。
- 10 萬名之後已進入**長尾區**,品質明顯下降(例:第 50,000 名附近為 unboxed、kpc、wrox、utenti;第 100,000 名附近為 herbeau、heimliche、kanchi、radda),含大量非英語詞與人名。作為 IME 英文預測,建議前 20k–50k 為高可信區,其餘視為候選池。
- 這是一份**種子清單**,不是人工校對過的金標;若要對外發佈英文預測品質,建議再跑一次人工/詞典校對。
- 若需要不同數量(例如 5,000 或 20,000),用上方同一條命令改 `head -N` 即可重現。
