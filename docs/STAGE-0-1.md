# 階段 0–1：開發基礎與基本輸入

## 基準與範圍

固定上游 McBopomofo commit `257da536ddaf590aae0e74e6adb9b415988344f6`，以 submodule 保存完整來源及 MIT 授權。基本注音解析、語言模型、候選窗和 Input Method Kit 控制器沿用上游；目前尚未加入 AI、英文混打或額外的選字邏輯。

`scripts/prepare_upstream.py` 從乾淨的固定版本建立副本，調整 bundle/input source IDs、IMK connection name、使用者資料目錄和顯示名稱，並使上游更新服務不被呼叫。`scripts/build.sh` 建置並產出 ad-hoc 簽名測試版。上游設定畫面和其他文字仍可能顯示小麥注音；品牌和服務項目尚待整理。

## 必須通過的階段 1 驗收

- [ ] 測試版與既有小麥注音並存，不共用詞庫和設定，不覆蓋原本 App。
- [ ] 系統可註冊及啟用測試版；標準鍵盤輸入「你好」，可顯示候選、選字、上屏。
- [ ] Backspace、左右游標、Escape、Enter、候選翻頁可正常運作。
- [ ] TextEdit、瀏覽器文字欄位及另一個 App 中切換視窗、切換輸入法，不丟字或重複提交。
- [ ] 測試切換焦點與關閉 App 時的未完成組字行為，記錄結果。
- [ ] 重啟後可再次啟用，且原有小麥注音與使用者資料未受影響。
- [ ] 完成上游測試及對隔離設定的自動檢查；記錄測試環境。

## 已知限制

目前不是全新實作，而是以固定上游為基礎產生隔離測試版。輸入來源的系統註冊、實際輸入、跨 App 相容性、macOS 15 相容性、簽名公證及散布尚未驗收。不要使用上游安裝器，它會操作原本小麥注音的安裝目錄。若需要安裝測試版，應先確認目標路徑及現有狀態，避免覆蓋資料。

## 可重複執行的安裝及檢查

- `./scripts/build.sh` 建置並驗證隔離版；`./scripts/test.sh` 執行不含線上更新 API 的上游測試。
- `./scripts/install.sh` 僅安裝至新的 `~/Library/Input Methods/ZhuyinLM.app`，既有目標存在即停止；安裝、註冊與啟用是不同步驟，不將註冊成功誤當成可輸入。暫存目錄測試確認首次複製與拒絕覆蓋均符合預期。
- `swift scripts/check_registration.swift` 在父輸入來源未啟用時會回傳失敗，作為目前問題的唯讀重現。此檢查不能代替真正的輸入測試。
- 現有機器為 macOS 27.0 (26A428)。[其他輸入法的同版系統觀察](https://github.com/metasequoiaime/msime/blob/develop/platforms/macos/README.md)顯示新的輸入法識別碼可能需重新登入才出現在列表中；這是待驗證的線索，並非本專案根因已確定。請保留現有登入及輸入設定，不直接編輯系統偏好。

## 登入後的實機測試案例

在 TextEdit 建立空白文件，確認選到 ZhuyinLM 的注音模式及標準鍵盤：

1. 依序按 `s u 3 c l 3`，觀察組字，再按 Enter，確認只上屏一次「你好」。
2. 輸入上述鍵序後開啟候選窗，選擇候選並確認畫面與輸出一致；測試翻頁、Escape 與 Backspace。
3. 測試尚未上屏時移動游標、切換 TextEdit 視窗及瀏覽器欄位，再回到原視窗；記錄內容是否丟失或重複。
4. 在 TextEdit、瀏覽器及另一個 App 重複組字與上屏；切回既有輸入法並確認功能正常。
5. 在其他鍵盤配置（倚天、許氏、倚天 26 鍵、IBM）各輸入一組字，確認配置能套用。

上述均須記錄實際觀察，不能依自動測試結果勾選。

## IMK 服務啟動檢查

直接啟動已安裝測試版的執行檔，確認程序在 3 秒後仍存活，測試後僅停止該次啟動的程序。這證明該次沒有立即退出，不能證明客戶端連線、輸入或提交正確。

## 重新登入後的系統輸入來源驗證

重新登入後，測試版出現在系統設定的繁體中文清單，原有英文介面顯示 `Bopomofo`，在清單中加入後父輸入法與主注音模式均顯示啟用，TIS 選取成功，服務程序啟動。這證明前一個登入階段無法新增的現象已解除，不能單憑這一項確定根因。

自動化工具送出 `su3cl3` 時，TextEdit 顯示字母；用已存在的 ZingIME 對照亦顯示字母，因此該工具的送鍵結果無法區分 IME 是否正確處理真實鍵盤事件。使用者以實體鍵盤輸入 `su3cl3` 並按 Enter，確認顯示「你好」；使用者亦確認空白鍵開啟候選清單、數字鍵選字正常；跨 App 與焦點切換仍未驗收。英文模式名稱已在準備腳本中調整，尚需重新建置並安裝後才能在系統中呈現。
